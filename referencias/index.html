Repositórios que já usei e recomendo.

Cada um vem com onde eu usei e por que vale a pena. Não é lista de estrelas do GitHub: só entra o que passou pelas minhas mãos. A lista cresce conforme eu uso coisa nova.

Backup de saves

mtkennerly/ludusavi

Backup e restauração de saves de jogos, com manifesto colaborativo de onde cada jogo guarda os arquivos.

Onde usei

É a base do SaveVault. Parti de um fork dele para construir meu gerenciador de saves de jogos de PC e emuladores.

Por que recomendo

Resolve o problema difícil, que é saber onde cada jogo grava o save, e entrega isso aberto e mantido pela comunidade. Eu só precisei cuidar da experiência por cima.

Claude Code

ThariqS/ai-newtab

Uma nova aba do navegador que o Claude Code monta como diário, a partir do que você acompanha.

Onde usei

Fiz meu próprio fork para testar o conceito, com os modos de leitura Jornal e Portal.

Por que recomendo

Mostra um jeito diferente de usar o Claude Code: sem chave de API, com a assinatura que já existe. Bom ponto de partida para ver um agente local fazendo algo útil no dia a dia.

Biblioteca de jogos

JosefNemec/Playnite

Gerenciador de biblioteca de jogos de vários launchers, com suporte a extensões.

Onde usei

Minha biblioteca de jogos vive nele, e escrevi várias extensões para ele: Busca de Jogos Locais, Playnite Hub e Repack Hub.

Por que recomendo

Junta Steam, GOG, emuladores e jogos soltos numa biblioteca só, e a API de extensões é boa de trabalhar. Para quem tem jogo espalhado, resolve.

C# WPF
Usei de verdade Ver no GitHub ↗ (JosefNemec/Playnite, abre em nova aba)
Motor de jogos

godotengine/godot

Motor de jogos livre e de código aberto, 2D e 3D, com editor próprio.

Onde usei

Fiz nele o Palworld Card Game e o Riftbound Card Game, para Windows e Android.

Por que recomendo

Leve, abre rápido, exporta para várias plataformas, e a parte 2D é ótima para jogo de cartas. O GDScript deixa o protótipo andar sem atrito.

Godot GDScript

Publicação

TryGhost/Ghost

Plataforma de publicação em Node.js, com editor, temas e API.

Onde usei

Este blog. Escrevo e edito no Ghost local, com tema próprio, e publico como site estático no GitHub Pages.

Por que recomendo

O editor é agradável e o sistema de temas em Handlebars é simples de dominar. Dá para começar com o tema padrão e trocar peça por peça.
